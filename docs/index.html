Built as a dedicated utility deck

Instead of fighting Apple's autocorrect and swipe engine, KeyDeck pairs with the native keyboard via the globe key and focuses purely on high-leverage voice and command workflows.

Rambler & Voice Edit

Speak messily, pause, or correct yourself mid-sentence. Single-pass Gemini audio (or OpenAI STT + LLM) turns rambles into crisp text, auto-inserts immediately, and gives you one-tap Undo, Shorter, Bullets, Casual, Work, and Raw chips.

"uh meet at 3—actually make it 4" → Let's meet at 4.

Alfred Palette + Mini-QWERTY

Tap the search bar to open a live fuzzy-search palette with a compact built-in mini-QWERTY. Evaluate math, convert units & timezones, generate UUIDs/timestamps, search clipboard clips, or expand parameterized snippets.

18% of 240 → 43.2 · 3pm est to cst → 2:00 PM CT

Explicit Mic Control

A persistent background audio session enables instant in-place recording without leaving your app — and a red Kill Mic button right in the keyboard, Dynamic Island, or Auto-Kill after dictation shuts the mic completely off whenever you want.

Mic On → 1 tap Kill Mic → hardware off immediately

Zero backend. Hardened for daily use.

Every network call goes straight from your iPhone to Google Gemini or OpenAI using your own API key. No relay servers, no analytics, no telemetry.

Device-Bound Keychain API keys are stored with kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly so they never leave your device in backups.
Ephemeral Zero-Cache HTTPS AI clients use ephemeral URLSessions with urlCache = nil and pass Gemini keys in the x-goog-api-key header, never in URL query strings.
Password Field Protection KeyboardViewController checks isSecureTextEntry and never reads or forwards text from password or PIN inputs.
App Store Privacy Manifests Ships with validated PrivacyInfo.xcprivacy across all three targets, strict ATS (NSAllowsArbitraryLoads = false), and encrypted App Group files.

Build on your iPhone in 4 commands

Requires Xcode 16+, iOS 17+, XcodeGen, and an Apple Developer account (required by Apple for App Groups, Shared Keychain, and Live Activities). 

git clone https://github.com/afloresescarcega/keydeck.git
cd keydeck
cp Config/Local.xcconfig.example Config/Local.xcconfig
# Edit Config/Local.xcconfig with your Apple Team ID & bundle prefix
xcodegen generate && open KeyDeck.xcodeproj
